## What this project is, in one paragraph

Cale is one local runtime that holds one model (Gemma 3n) and lets any app use it with goals instead of settings (speed, first-word time, memory, quality, power). The same app must feel the same on a fast Mac and on an old laptop. The current job is a funding demo of that idea: download one thing, five apps work, on a Mac and on an old HP laptop (Windows with a GPU, then Linux on the CPU). Branch: `phase5-cross-platform`. All work of this session is in the working tree. Nothing is committed by me (an automatic "wip: end of turn" commit exists).

## Traps that cost time this session

| Trap | What to do |
|---|---|
| A native Vulkan or CUDA error poisons the whole process. After it, even the CPU load crashes. | Do GPU work only after a child process proved it (already built). Never call GPU code in-process first. |
| My job scripts deleted `predict.json`. That removes the install table and tests a path no real user has. | Never delete `predict.json` in test jobs. Run `python -m cale.tune --profile full` instead. |
| zsh `echo` turns `\c` in Windows paths into "stop". | Use `printf '%s\r\n'` to write `.ps1` files. |
| macOS `sed -i` needs an extension, and `sed` with a path that has `/` breaks. | Edit with Python. |
| `pkill -f cale.server` on the Mac can stop the installed Cale. | Kill by pid only. |
| `hp put FILE` with a name that exists can silently keep the old file. | Use a new file name every time (this session used `_pNN` suffixes). |
| Rebooting the HP is fast (about 30 s). A ping loop can miss it. Check `LastBootUpTime` and event ID 1074. `shutdown /r` may say "in progress" and still work. | Check the event log, not ping. |
| The Linux `.run` launcher looks in `~/.local/share/cale`, not `CALE_HOME`. | On the test home, run `cale/install.py --update` by hand from the unpacked payload. |
| The scorecard needs the Cale Hub running (port 47802 on Windows). A reboot kills it. | Start it: `python -m cale.hub` with `CALE_HOME`, `CALE_HUB_PORT`, `PYTHONPATH=...\runtime`. |
| A model object made before a Cale restart used to give "Unknown model". | Fixed (objects revive). Keep `objects.json`. |
