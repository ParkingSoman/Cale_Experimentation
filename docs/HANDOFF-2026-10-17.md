# Handoff 2026-10-17: Cale became a real program

Read `CLAUDE.md` first. The demo run sheet is the top of `demo/README.md`. The look is in `cale/brand/README.md`.

## What changed in one day

| Area | Before | Now |
|---|---|---|
| Cale's own screens | A web page at `127.0.0.1:47800` in the browser | Native windows (Mac: Swift, Windows: C#). The carrot mascot (`cale/brand/carrot.svg`). |
| Cale's chat | None. Open WebUI was a separate demo app. | AnythingLLM v1.18.0 (MIT), rebranded as Cale, opens inside Cale's own window (`cale/chat.py`, `cale/anythingllm/`). |
| Quick Notes | Opened in the browser at port 8821 | A desktop app. Own window, own icon. The app's window program is its main program, so the Dock shows its name. |
| Rewrite | Browser app at port 8825 | A website that calls Cale from the browser (`web/rewrite/`). Built, not tested in Chrome, not published. |
| Websites reaching Cale | Refused (any Origin header) | A narrow, deny-by-default path (`docs/API.md`, "Websites"). |
| Allow question | Said "app" always | Says "website" for a site. Unanswered or refused questions are counted per site (`cale/sites.py`). |

## Decisions made on 2026-10-17 (do not re-ask)

- Cale is a real program with its own chat. Not a web page.
- Chat base is AnythingLLM, not Open WebUI (Open WebUI's licence only lets you remove its branding for 50 or fewer users).
- The mascot is a carrot in sunglasses. Cartoony and down to earth. The green kale look is retired.
- Rewrite is a real website, to show that Cale supports both desktop apps and websites.
- A website must pass the same rules as Chromium uses for permission questions. No invented limits.

## Traps

| Trap | What to do |
|---|---|
| `cale/tests/e2e.py` used to default to the real Cale (47821). | It now needs `--base` and refuses 47821. Start a test Cale on a spare port. |
| The chat quits when the shell that started it ends. | Start it, test it, and stop it in ONE shell command. |
| Test switches `CALE_DEBUG=1` and `CALE_AUTO_APPROVE=1` do nothing for a Cale that already runs. | Put them in the test Cale's own environment. Never ship them. |
| An auto-commit hook saves work as `wip: end of turn` commits. | Push yourself. The repo is `ParkingSoman/Cale_Experimentation` (private). Use the `ParkingSoman` `gh` login. |
| ssh to the HP breaks `$` in PowerShell. | Write a `.ps1`, copy it, run it with `-File`. |
| scp dies near 90 MB. `Expand-Archive` hangs on big zips. | Serve files from the Mac and fetch with `curl.exe`. Extract with `tar -xf`. |
| Windows paths over 259 characters. | The chat bundle's longest path is 178 characters. Delete with `cmd /c rmdir /s /q "\\?\..."`. |
| 250% screen scaling on the HP | Window sizes in C# must be multiplied by dpi / 96. |
| An empty file in a zip made by Python is a 2-byte stream | `SelfExtract.cs` writes empty files by hand. Do not undo that. |
| Bundles hold native files for one OS | `dist/chat` is Mac only. `dist/chat-win` is Windows x64 only. Linux has no chat. |
