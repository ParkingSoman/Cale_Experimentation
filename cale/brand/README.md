# Cale's look

Cale is cartoony and down to earth. Its mascot is a carrot in sunglasses. Not sci-fi, not "supertech".

| File | What it is |
|---|---|
| `carrot.svg` | The mascot. The one source for every picture of Cale. |
| `carrot.png` | The same picture, 512 px, see-through. For code that cannot read SVG (Windows windows). Made by `cale/host/mac/MascotIcon.swift`. |

## Colours

| Name | Hex | Use |
|---|---|---|
| Carrot | `#f58a1f` | Main colour. Buttons, progress bar, links. |
| Outline brown | `#3b2314` | Text, and the thick outline on cartoon shapes and buttons. |
| Cream | `#fff1d6` | Window and page backgrounds. |
| Sky | `#8fd3f4` | App icon background. Soft accents. |
| Leaf | `#4aa34f` | The carrot's leaves only. Never a theme colour. |
| Soil | `#8a5a3b` | The ground in the setup window. |
| Ink | `#1b1722` | The sunglasses. |

Text on Carrot orange is Outline brown, never white (white on orange is too faint).

## Voice

Short, friendly, plain. No tech words. "Planting Cale", "You are all set".

## Rules

- Cale's own screens and its chat use this look. Apps from other developers keep their own look.
- The old green kale look is retired.
