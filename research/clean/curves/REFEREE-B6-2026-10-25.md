## The three most important fixes, ranked

1. T15: make the proof stand without the script. The theorem claims only 0 < min < 1/16 and attainment. Proof in
   three steps, all by hand. (a) The explicit build gives min <= 1/32 < 1/16 (already in the paper). (b) The class
   of outputs is the union of 16 sets {X_S beta + b 1 : beta in +-S, b in R}. Each is a linear image of a polyhedral
   cone, so it is a closed polyhedral cone. A finite union of closed sets is closed, so the distance from tau to it is
   attained, and it is positive iff tau is not in the union. (c) tau = (1, 0, 0, 2) is not of the form
   t relu(mu^T z) + b. The unit's off set must have equal tau values: {}, {i} or {2, 3}. {2, 3}: b = 0, t > 0,
   -m_1 = 1/t, -m_1 + m_2 = 2/t, so m_2 = 1/t > 0, against mu^T z_3 = m_2 <= 0. {2} or {3}: an on point then needs
   t mu^T z_i = 0 with mu^T z_i > 0, impossible. {1}: b = 1, the on values (-1, -1, 1) have mixed signs. {4}: b = 2,
   the on values (-1, -2, -2) force m_1 = 0, and then mu^T z_1 = 0 is not > 0. {}: no affine map fits (z_2, z_3 force
   w_1 = 0, b = -w_2; z_1 gives b = 1; z_4 then gives 0, not 2). Then "the minimum equals 1/32" becomes a Remark
   checked by the script, or a 16-row table in the proof. Add C_f = Var relu(s^T z) = 1/4 > 0 for the T11 comparison.
2. T14: state the theorem as what is proved. (a) Title "at width (1, 1)", with "below the visible widths" in the
   Comment and the note that d_1 = 1 instances are solved by T13. (b) Main claim = the decision problem (value = r for
   rational r) is NP-hard. (c) Either drop "no polynomial-time algorithm computes the optimal fold" or qualify it as
   "in the sense of Hillar and Lim, Theorem 1.12", name their model in the literature row, and replace the "onto"
   justification by the polynomial map h = 1/2 H^T eta from an optimal build to a best rank-1 approximation.
3. Lean and D7 statements. (a) `rank1_fit`: add the equality case, and add a Lean lemma for the finite identity
   1/2 sum_q \|H X_q + omega_q eta_perp kappa^T\|^2 = sum_q \|X_q\|^2 + 1/2 \|eta_perp\|^2 \|omega\|^2 \|kappa\|^2 given
   H^T H = 2I and H^T eta_perp = 0; until then the Lean line must not say "with equality". (b) D7: fix phi (step gate),
   state a decision version with input (chain, law, k), and add to the route that the student has a free output bias
