## Numbered findings

1. **TV7: the map is free, so the statement is trivial; M_delta leaves out the claim that sees block 2.**
   COARSE-THEORY.md lines 4957 to 4963 and 4971 to 4976; also line 4877 (B.V.2 intro) and line 4952 (TV6 Comment).
   - The conclusion says that no bound "that depends only on the errors of claims of the types of DM11 to DM13"
     tends to 0 with them.
   - DM6 (completeness) is not defined for areas, so a map may hold any set of claims.
   - Take the map with no claims. The bound is then a constant. "0 when all are 0" makes the constant 0, and it
     fails for any N with V_area > 0. So the statement holds with no example at all. TV7's content lies only in
     which claims the map must hold. The statement does not say which.
   - TE5, whose reading TV7 cites, has an anchor here: its M_W is complete for G (DM6). TV7 has no such anchor.
   - M_delta lists the areas span(e_3) and span(e_4). It holds no block-read claim for them. Neuron 2 reads span(e_3)
     with read vector W e_3 and writes W e_4, with W = 1/delta. So:
     - eps_br(span(e_3)) = delta^(-2);
     - eps_br^w(span(e_3)) = delta^(-4) |h_1|^2 / (|h_1|^2 + 1), which is about (2/3) delta^(-4).
   - Both go to infinity. The block-read claim of span(e_3) is "a claim made one block at a time", and it sees block
     2's gain. So the two-block family does not exclude a bound in the block-read claims of every area of the family
     plus the claims about D. The Comment says that "each block's own errors see only its own weights". This is true
     only because the map leaves those errors out. TE5 part 4 states the matching fact (the quiet error goes to
     infinity). TV7 does not.
   - Fix (a proof, not an experiment). Use one block and let the logits carry the gain:
     - block 1 reads delta e_2 and writes e_3;
     - U has rows t e_3^T and 0, with t = s nu_0 nu_1 / delta and nu_1 = (3 + delta^2/3)^(1/2);
     - then y_N = (s x2, 0).
   - With the area family {span(e_1, e_2), span(e_1), D, span(e_3)}:
     - every block-read claim of every area has eps_br <= delta^2 and eps_br^w <= (2/3) delta^2;
     - the energy claims (D, l) for l = 1, 2 and (span(e_3), 2) have error 0 (|P h_1|^2 = delta^2/3);
     - the readout claim (D, {0}) and all write claims have error 0;
     - the lower bound c(s) has the same proof.
   - This is TE5's mechanism exactly (a tiny leak read with a large weight at the readout). Restate TV7 for maps that
     hold a block-read claim for every area, the energy claims (D, l) and a readout claim per group. If the two-block
     version stays, weaken the statement to "claims about D" and state the divergent span(e_3) errors. Update node
     N-amplify's text to match.

2. **eps_br^w is not invariant under the stream-scale symmetry, and that symmetry produces TV7's error list.**
   DM11 lines 1258 to 1262; TV7 lines 4959 to 4960 and 4982 to 4983.
   - In the norm form, multiply e, every W_l and every c_l by c > 0, and every eps_l by c^2. Keep R_l, b_l, U and
     c_y. Then n_(c^2 eps)(c h) = n_eps(h), so every read and the logits are unchanged at every input. This is an
     exact symmetry of Definition DV1. In the no-norm form the same holds with R_l and U divided by c, for every sigma.
   - Under it, eps_br^w scales by c^2 and eps_br is unchanged.
   - Start from N_1 (TV7 with delta = 1). Take c = delta, then F1 on neuron 1 with a = delta. The result computes the
     same function as N_1 and has exactly TV7's error list: eps_br(D) = delta^2, eps_br^w(D) = (2/3) delta^2,
     every other listed error 0 (the energy errors stay 0, with |P_D h|^2 = delta^2). Only eps_l = delta^2 differs.
   - So "eps_br^w does not change under the rescaling of Fact F1" is true but does not do the work it is cited for.
     The errors alone cannot tell TV7's family from a symmetry orbit.
   - What makes TV7 real is that it fixes eps_l = 1. Then the ratio |P_(e3) h_1|^2 / |h_1|^2 =
     (delta^2/3) / (2 + delta^2/3) moves with delta. On the orbit of N_1 this ratio stays 1/7. No symmetry
     changes it. Say so in the proof.
   - Fix: normalize, for example replace |w_(l,i)|^2 by |w_(l,i)|^2 / E_P |h_l|^2. This is invariant under F1, under
     stream scaling (both forms) and under F13 rotation. TV7 survives it: neuron 1's term is about delta^2 / 3.
   - By contrast, DM14's error is invariant under stream scaling: lambda goes to c lambda, u to u / c, and T_l does
     not change.

3. **DM11 eps_br^w: "0 exactly when" is false as worded; one claim, two errors.**
   DM11 line 1261 to 1262; TV7 line 4958.
   - A term Lip_l^2 |w|^2 |P_A r|^2 E_P |n(h_(l-1))|^2 is 0 iff one of these holds:
     - Lip_l = 0;
     - w = 0;
     - P_A r = 0;
     - h_(l-1) = 0 on all of P.
   - "Reads nothing of A on P's normed stream" reads naturally as (P_A r) . n(h_(l-1)(x)) = 0 on P. That is weaker:
     take P_A r != 0 and a stream with no part in A on P. Then that reading of the claim holds, but the error is > 0.
   - Write the condition as above. It is the claim "no neuron that writes reads A". It is a different claim from
     eps_br's "no block reads A". So either make it a separate claim, or keep one claim with one error. TV7 says
     "the two block-read claims of D", but T5 gives each claim one error.
   - DM11 is stated for any sigma of DV1, so Lip_l can be infinite there. Add "Lipschitz sigma_l" to the
     definition, or define the term only then.

4. **DM14: the error depends on a decomposition that the claim does not name.** Lines 1297 to 1306.
   - lambda_l[A], T_l[A, B] and u_A all use A_1, ..., A_m. Different decompositions give different errors for the
     same (D, l).
   - So "define from N, P and D alone", and T5's "computed from N, P and the claim alone", fail for the claim
     (D, l) as named.
   - Fix: either name the claim (D, {A_k}, l), or fix the decomposition from the map. For example, use the own parts
     of the laminar family plus the orthogonal complement of the family's sum. That is an orthogonal decomposition.
   - Also, DM14 uses Lip_l of N's sigma_l. This needs a Lipschitz sigma. Node S-purestream lists that premise only
     "for TV6 to TV8".
   - The rest checks:
     - the leak formula is TV6's projection leak (algebra in the table);
     - "0 exactly when" is a real equivalence;
     - R-cutclaim is the right record (the claim names D, so with the group it names the cut).
