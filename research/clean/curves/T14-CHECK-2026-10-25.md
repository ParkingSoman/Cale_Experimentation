## Task 2: routes

Setup. After the reduction, the width-(1,1) value is min over unit h, kappa, omega of \|T - lambda h(x)kappa(x)omega\|_G^2 where G is the data-covariance form. Three modes: n1 (units above), n2 (units below), n3 (window).

### (b) odeco, proof (V)
<T, h(x)kappa(x)omega> = sum_i lambda_i a_i b_i c_i with a_i = <u_i,h> etc. and sum a_i^2 <= 1. Then sum_i lambda_i a_i b_i c_i <= lambda_max sum_i \|a_i b_i c_i\| <= lambda_max (sum a_i^2)^(1/2) (sum b_i^2 c_i^2)^(1/2) <= lambda_max max\|c_i\| (sum b_i^2)^(1/2) <= lambda_max. Equality at (u_1, v_1, w_1). So sigma = lambda_max and the best rank-1 term is the largest one.
For a chain: slices T_q = sum_i lambda_i w_i(q) u_i v_i^T. This means the channel pairs (u_i, v_i) are mutually orthogonal in both modes and the spatial profiles w_i are orthogonal. A trained network has no reason to have this. It can be tested after the fact (cheap). It is a certificate, not a hope. Near-odeco: the power method with good start recovers it (Anandkumar et al. 2014, R), but then the result is a certified local solution only if a bound matches (see d).
Cheap bounds for any T: upper = largest singular value of any flattening. Lower = HOPM. If they agree, done.

### (c) small dimension (A, worked out)
Fix omega on the sphere in R^{n3}. Then max over h, kappa is sigma_max of the n1 x n2 matrix M(omega) = sum_q omega_q T_q. So sigma = max over omega of sigma_max(M(omega)). This has n3 - 1 free variables.
- n3 = 1: SVD. Polynomial.
- n3 = 2: omega = (1,t)/sqrt(1+t^2). sigma^2 = max_t lambda_max(M(t)^T M(t)) / (1+t^2). With P(lambda,t) = det(lambda I - M(t)^T M(t)), the optimum is a critical point of P(lambda (1+t^2), t) = 0, so a root of a resultant of two bivariate polynomials of degree O(min(n1,n2)). One variable after elimination. Exact value (an algebraic number) is found in polynomial time, so the decision "= r" is polynomial. It is NOT a 2x2 pencil, but a one-parameter problem. Checking the exact degree bounds was not done.
- Fixed n3 = s: critical points of a polynomial system in s variables. Real algebraic geometry (Basu, Pollack, Roy, R) gives n^O(s). Same argument holds for any one fixed mode.
- Hardness instances of Hillar and Lim need all three sizes to grow. T14's hard instances need min(n1,n2,n3) unbounded.
So: the hard case is "wide window, many units in and out". Small windows are tractable; T14's source of hardness is the number of window offsets AND channels together.
Not run numerically. A quick test (grid over t against HOPM) would take 5 minutes.

### (a) symmetry (partly V, partly open)
- Index-symmetric tensors: still NP-hard (Hillar-Lim Section 1.8, Theorem 10.2, V). Not the right notion here.
- Group symmetry with Pi = identity: would embed every hard instance (orbit slices repeat; the optimum has equal omega on an orbit; value = |G| (\|T\|^2 - sigma^2)). But H-eq fixes Pi as the cyclic shift on N members, so this trivial representation is excluded. Warning: if D3b is ever weakened to "any representation Pi", hardness survives (A).
- With Pi the cyclic shift: in the Fourier basis, orbit o and frequency f give a slice that is a shifted diagonal, T_hat[m, m-f, (o,f)] = d_{o,f}(m). Then sigma^2 = max over unit h, kappa of sum_{o,f} (sum_m d_{o,f}(m) h_m kappa_{m-f})^2.
  - f = 0 only: x = h.kappa ranges over the l1 unit ball. The objective is a convex quadratic form in x, so the maximum is at a vertex: sigma^2 = max_m sum_o d_o(m)^2. Polynomial (A).
  - mixed f: a quartic in (h, kappa) with sparse structure. I found neither a hardness reduction nor an algorithm. This is the real content of D3b. Open.
- Also note: symmetry of the chain does not force a symmetric optimum (the maximizers of a non-convex problem can break symmetry). So averaging over the group does not reduce the problem.

### (e) data covariance (A)
- A Kronecker covariance across modes 2 and 3 (channel x window) is equivalent to white by the invertible multilinear change T -> (I, S_a^(1/2), S_q^(1/2)) T. Rank-1 structure is preserved. So still NP-hard. In particular position-independent but channel-correlated data, or separable space-channel data, give no relief.
- Hardness is for worst-case T and a fixed white law. A fixed non-white non-Kronecker law: no reduction known to me, and no algorithm. Unknown.
- A low-rank covariance (data in an r-dimensional subspace) shrinks n2 n3 to r, so the problem becomes the fixed-dimension case of (c)/(b') only when r is small. Real image data has decaying but full-rank covariance. No exactness from that.
- Real teacher weights T are not worst-case. Hardness says no polynomial algorithm for all T; it says nothing about a particular trained net. So the practical route is (d)+(d'): HOPM from many starts gives an upper-bound-matching certificate (SOS or flattening bound) for the given T.
