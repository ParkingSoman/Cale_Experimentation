### E1 (error). D13 comment and T13 comment: "with pointwise edges, dim O_l <= k + r" is false. "This recovers Corollary T11.1" is false.

Location: D13, the Comment ("With pointwise edges (Q = {0}), dim O_l <= k + r"). T13, the Comment ("with pointwise edges
and r forced reads it is at most k + r (this recovers Corollary T11.1)").

Witness. Pointwise edges, self-gated, m = 3, N_1 = 1, N_2 = 5, N_3 = 1, k = 1. Let S_1 = 1, so r = 1 exactly. Let
S_3 = I_5, so gate 3 reads all of v_2. The pull-back W_2^T S_3 = w_1^T is 1 x 5, so R is all of R^1 and r = 1. But O_2 contains the columns of
S_3, so O_2 = R^5 and d_2 = 5 > k + r = 2. Corollary T11.1 builds an exact read-faithful build with width k + r = 2
at layer 2. So T13's widths are not T11.1's widths.

What the definition does give: dim O_m <= k and dim O_l <= dim O_{l+1} + r_{l+1}. So
dim O_l <= k + sum_{j > l} r_j, plus r_1 at l = 1. That is the valid bound.

Root cause. O_l is only the observable part. Kalman's minimal realization is the part that is both reachable and
observable. In the witness, v_2 = g_2 w_1 v_1 lies in a 1-dimensional subspace, and T13 does not use this.

Fix (a proof, not a weaker statement). Define the reachable space Rch_l = span{v_l(x, p) : x, p}. Rch_1 is in
col(K^T), and Rch_{l+1} is in the span over q of w_l(q) Rch_l. Choose B_l whose rows, restricted to Rch_l, are a basis
of O_l restricted to Rch_l. Prove the T13 induction on Rch_l only: the edge equation B_{l+1} w_l(q) x = w'_l(q) B_l x
needs to hold only for x in Rch_l, and uniqueness still holds on that subspace. In the pointwise self-gated case this
gives k + r and recovers T11.1. Until then, replace "k + r" by "k + sum_{j > l} r_j".

Consequences. The phrase "below the visible widths" in the T13 comment, in D.1 row 12 and in the D3b sentence is not
where the linear argument stops. The reachable reduction is still linear.

### E2 (error). Kalman 1963 row misstates the borrowed result.

Location: A.4, row "Kalman 1963".

The row says: "the smallest state space that reproduces a linear system's output is the observable part". Kalman's
result is that the minimal state space is the reachable AND observable part. The observable quotient alone is minimal
only for a reachable system. The row does not state that hypothesis. E1 is the consequence.

Second problem in the same row. The row says that the layers play the role of time. The D13 comment says "with the
offsets in the role of time steps". These disagree. The row's version is the right one. The offsets are spatial, so the
system is time-varying and multidimensional (Fornasini-Marchesini or Roesser form), not the time-invariant system of
the 1963 paper.

Fix: "minimal = reachable and observable (Kalman decomposition). We use observability only, so T13's widths are an upper
bound on the minimal widths." Make the D13 comment say layers = time steps.

### E4 (error, inside a conjecture). Conjecture D6: the "exactly when" condition is incomplete.

Location: D.7, the displayed stationarity condition.

1. A change of S'_l changes g'_l. That rescales v'_l, v'_{l+1}, and so on. So it changes S'_j^T v'_{j-1} for every
   j > l, and so it changes g'_j. The displayed term has only the g'_l factor. The missing terms vanish only if
   grad phi_j(t) . t = 0 for all t, that is, phi_j is constant along rays. If phi_j is also continuous at 0, it is then
   constant (phi_j(t) = lim phi_j(s t) as s -> 0 = phi_j(0)). The tag asks for every phi_l differentiable, so for every
   non-constant gate the missing terms are present.
2. "Stationary point over all self-contained builds" needs the derivative along every parameter: K', w'_l, H', c' and
   the S'_l. A change of K' or of w'_l also moves the gate reads. The displayed condition covers the S'_l only.
3. "In general" is not a mathematical quantifier. "Strictly between" is false in some cases: T11.2 part 4 shows that
   T11's value equals T12's bound when lambda_0 is among the k largest. Also the best build need not be attained.

Fix: state it existentially and as an infimum. "There is a self-gated chain and a law P such that the infimum of D2_P
over self-contained builds of uniform width k is strictly below the value of T11 and strictly above the bound of T12."
Write the stationarity condition as the full chain-rule derivative over all parameters (Step 1 of the route), or drop
"exactly when".

### G1 (gap). Theorem T13 part 3: the prefix claim is not proved, and it is false for the head as written.

Location: T13 part 3 and its proof ("Extend a basis ... (`prefix_span_mono` for the prefix spans)").

Edges. The claim holds, but it needs an argument. Let B_l(k) be the first d_l(k) rows of B_l(k'). The rows of
B_{l+1}(k) w_l(q) lie in O_l(k). By uniqueness, the first d_{l+1}(k) rows of w'_l(q; k') are zero after column
d_l(k), and their first d_l(k) columns are w'_l(q; k). So the stored edge is block lower-triangular. This must be written.
The same argument gives M_l(k') = [M_l(k); 0], because every gate read lies in O_l(k) for every k.

Head. The head at width k is H'(k) = U_k C(k). With an arbitrary extension of the basis at layer m, the rows k + 1 to k'
of C(k') can have entries in the first d_m(k) columns. Then the first d_m(k) columns of U_{k'} C(k') are not U_k C(k).
So "prefixes of one stored build ... and a bias per width" is false for the head with an arbitrary basis.

Fix: fix the basis at the top layer. Take the rows of B_m(k) to be e_j^T P_perp H for the j <= k with mu_j > 0. These
rows are independent, because each such e_j lies in col(P_perp H). Then C(k) = [I; 0] and the head at width k is the
first columns of U. Rows with mu_j = 0 contribute zero almost surely, so they can be dropped. Then write the block
argument above.

### G2 (gap). Corollary T11.2: the headline is assumed in the tag, and "Theorem T10 applies" is too broad.

Location: T11.2 title, tag, part 1, part 3, the Comment; D.1 paragraph "(b) ... under symmetry r = 1, the orbit sum".

1. The title is "with symmetry, the only forced read is the orbit sum". The tag assumes that every read matrix is
   s_l 1. Symmetry does not imply this. Witness: phi(S^T v) = |S^T v| with S the cosine and sine reads of mode n. This
   gate is invariant under the cyclic shift, and its reads span 2 dimensions, so r = 2. This is the norm gate of Worrall
   et al. 2017, which the literature table cites. Fix: retitle to "with symmetry and invariant single-column reads". Make
   the same change in the Comment ("under symmetry the whole network ... folds to one unit per layer") and in D.1 (b).
2. "So Theorem T10 applies." T10 is tagged H-gate. Its proof of parts 1 and 2 uses only invariant gates, pointwise
   circulant edges and H-symN, so parts 1 and 2 carry over. Part 3's build (insert P_S after every layer) keeps the
   network's gates from outside. Under H-selfgate it is self-contained only if mode 0 is in S. Fix: "Theorem T10 parts 1
   and 2 apply, and the value of part 3 is the bound of T12."
3. Part 3 says that the best build "keeps mode 0 and the k - 1 modes n != 0 with the largest lambda_n". The proof
   ("Theorem T11 parts 1 and 2 with r = 1") gives only the value. To identify the reads, add this step:
   P_perp A - C_yf C_f^{-1} 1^T = P_perp A (I - P_0), so Lambda' = U'^T P_perp A (I - P_0)
   = U'^T Y'(I - P_0) Chat^{-1/2}. The rows of U'^T Y'(I - P_0) are right singular vectors of Y'(I - P_0). They are
   real Fourier modes (within tied pairs, choose a real mode basis). Chat^{-1/2} keeps each mode. With an odd k - 1 the
   cut falls inside a pair (n, -n), as in T10 part 4. Say so.
4. Tag: H-eq is defined for a gated chain in the sense of D11. Write "the conditions of H-eq parts 1, 3 and 4, for a
   self-gated chain". Part 2 uses chat(0) > 0. That follows from Chat positive definite, so it is covered. Say it.
