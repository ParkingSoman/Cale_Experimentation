## Findings

**1. (gap) The closing comment of B.7: "must sit outside" does not follow.**
The comment says that a complexity statement for the width-1 Gaussian case "would need this written out, and it is
not claimed here". The next sentence says "Any hardness result for affine gates must sit outside those premises". The
second sentence needs a polynomial-time algorithm inside the premises. The paper does not claim one.
The list after the colon reads as exhaustive. It leaves out some r_j = 0, several read columns, Q = 0, and m_a != 0 or
Sigma singular without a constant entry.
Fix. "If the root-isolation route is written out (rational Sigma, M, s, alpha, beta, bit model), a hardness result for
affine gates must use a case outside these premises, for example ...". Add one line on rationality:
prod_j (mu - lambda_j) is the minimal polynomial of N Sigma (similar to Q, so diagonalisable), which has rational
coefficients. So g(mu) prod_j (mu - lambda_j)^3 is in Q[mu].

**2. (gap) Fact (iv): the bias-entry cost is unconditional. Anderson 2003 is still cited outside the table.**
(a) Let a_0 be a constant entry equal to 1. Then row 0 of Sigma is zero. So row 0 of L = Sigma K' G^+ is zero, and
b_0 = (m_a)_0 - (L K'^T m_a)_0 = 1. So b != 0 for every kernel, and the alternative "b = 0" in the cost sentence never
happens. With a constant entry, linear-seen holds if and only if 0 is not in A. Write A = K'^T m_a + range(G). Then
0 not in A means K'^T m_a is not in range(G), so range(G) != R^k and rank Cov(w) <= k - 1.
Fix. "With a constant entry, b != 0, so K' is linear-seen if and only if some combination of its units is 1 almost
surely. Then Cov(w) has rank at most k - 1: one dimension of V is spent on the constant."
(b) "Equality on A": add "the set where the two affine maps agree is closed and has probability 1, so it contains the
support of w, which is A (w - K'^T m_a = G^{1/2} xi)".
(c) The T17 Lean line still says "facts (i) and (ii) are classical (Anderson 2003, Theorem 2.5.1)". There is no table
row, and rule 5 requires one. Fact (iii) now proves the singular case in the paper. Delete the citation. Do not add the row.

**3. (error) Conjecture D9's route.**
(a) Direction. D9 asks whether "infimum <= r" is NP-hard. Copositivity is co-NP-complete. A many-one reduction from
copositivity gives co-NP-hardness. The existential problem matches non-copositivity: there is x >= 0 with
x^T C x < 0. That problem is NP-complete: it is the complement of the problem in the Murty and Kabadi row. The route must also turn the strict "< 0"
into the non-strict "<= r". A bit-size gap argument does this, but it must be named.
(b) Degrees. For n_y = 2 and beta != 0, the build's centred output is h (alpha q' w^2 + beta w). Its closure is the
regression on the two features (w^2, w). The value is Var(P_perp y) - c^T adj(G) c / det G, with
c = Cov(P_perp y, (w^2, w)) and G = Cov((w^2, w)). Both c^T adj(G) c and det G are forms of degree 6 in kappa.
"A ratio ... from moments up to order four" is right. "The denominator (a fourth moment of kappa^T a)" and "the
numerator encodes an arbitrary quartic form" describe only beta = 0.
(c) Even at beta = 0 the numerator is not arbitrary. With z = P_perp y (a scalar) and C = Cov(z, a a^T), the value is
[Var(z) D(kappa) - (kappa^T C kappa)^2] / D(kappa), with D(kappa) = Var((kappa^T a)^2). For a finite law,
D = sum_i pi_i (kappa^T a_i)^4 - (kappa^T Sigma_2 kappa)^2. Put r' = 2 r (the 1/2 of D2_P, with the position weights
absorbed). Then "value <= r" is the sign of (Var(z) - r') D(kappa) - (kappa^T C kappa)^2: a positive combination of fourth powers minus two squares of quadratic forms.
C and Sigma_2 are not free, because the law fixes them. To encode sum_ij C_ij x_i^2 x_j^2 in this form is the whole
difficulty.
(d) D9 does not say "one position". The comment it cites is for one position.
Fix. Restrict D9 to beta = 0 and one position (the gate is then alpha t, and y is a quadratic form times a linear map).
State the route as: reduce from non-copositivity; the instance must realise the quartic as
(Var(z) - r') D(kappa) - (kappa^T C kappa)^2. List as obstacles the moment cone, the two squares and the strict
inequality. Also change the D.7 Note to "the affine-gate case on finite laws with n_y = 2 at width 1 is Conjecture D9".

**4. (gap, wording) Proposition T17.3 part 4: the dimension count is right but not written; "maximum" should be
"supremum"; the words overstate.**
The count holds in every case.
- p not proportional to stilde: dim {stilde, p}^perp = d - 2 >= k - 1, which is exactly k < d.
- p proportional to stilde: then p = c stilde with c^2 = c, so p = stilde, and the dimension is d - 1.
- Case (b): dim stilde^perp = d - 1 >= k (or d when stilde = 0).
So kappa_{k-1}(p), kappa'_k and a W' always exist. The converse ("every such W'") needs that existence, so state it.
The constraint set in (a) is the sphere with centre stilde/2, minus the origin, which lies on it. The set is not compact, and
p^T Q p / |p|^2 has no limit at 0. (a) is attained when f has a maximiser with p != 0. Otherwise it is a supremum.
(Along the sphere, the limsup of h at 0 is at most beta^2 kappa'_k, so the maximum of f is still the larger of the two
values. Only the word must change.)
"k - 1 principal directions of Q away from it": these are top eigenvectors of the compression of Q to
{stilde, p}^perp, not eigenvectors of Q. In case (b) there is no read-carrying direction.
Fix. Add "{stilde, p}^perp has dimension at least d - 2 >= k - 1 (d - 1 if p = stilde)". Write "supremum" in (a). In
the words, write "top directions of Q compressed to the complement of stilde and p".

**5. (wording) Proposition T17.3 tag and part 1.**
(a) "For fixed p the coefficient alpha^2 |p|^2 + beta^2 is positive" is false at alpha = beta = 0. The conclusion still
holds, because then f = 0. Write "non-negative".
(b) "k < d allows the padding": padding to rank k needs only k <= d. Here k < d only excludes the trivial case k = d.
Give the right reason, or delete the clause.

**6. (wording) Proposition T17.1: the tag, B_V, and the intro.**
(a) The tag requires |phi'| <= L. Part 5 is a step gate. Split the tag by parts.
(b) Part 3 writes D2_P(B_V). The bias of B_V in T17 is c + alpha rho_1 M C_e s, and alpha is not defined for a curved phi.
Write "the build of part 2 with its best bias".
(c) The B.7 intro says "for gates that switch, this section gives a price (T17.1)". The price is part 3, for Lipschitz
gates. For the step gate, part 5 gives the seen mean and no price. A weaker statement to prove, if one is wanted: with
tau^2 = Var(s^T Gamma w) > 0, the price is O(sigma / tau) times a moment of P_perp M a (Hoelder is needed, because t and w
are dependent). It depends on V through tau, so it is not uniform. That is the honest form of a step-gate price.
