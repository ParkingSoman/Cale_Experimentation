## 2. Ranked findings, each with a one-line fix

1. **T5 part 5 is false for F >= 2.** The best read needs Chat(n)^(-1/2) (part 3), so the data enters through the pair (Chat(n), Phihat(n)), and the write also through M W.
   Fix: "the optimal objective depends only on the spectra of the products; the read space depends on the pairs (Chat(n), Phihat(n)); the write also depends on M W". In part 3, change "the best" to "a best" (or add a strict-gap premise), and prove Chat(-n) = conj(Chat(n)).
2. **The H-contour estimator maps network covariance to D(s) through unnamed hypotheses.** These are shot-noise additivity, a Poisson curve process with no density variation between images, D9 detectors, and the abs(y') <= s' cut. For curvature-tuned members the p = 1 (direction-process) branch has no derivation, while p = 3 survives (sigma^2 s^3 / 180 at matched curvature).
   Fix: add a Lemma "(under: H-contour, H-clean, H-shot, H-detector) Cov_ij(v) = lambda times the pair density convolved with the tuning kernels". Name H-shot and H-detector in A.3. Derive D(s) on the cut region. State that the test is one-sided (p = 3 or not) for curvature-tuned members.
3. **The D.1 chain overstates links 1, 4, 5 and 8, and two links are absent.**
   Fix: add a Hypotheses column with the exact tag of each link (link 1: fixed read, second order, frozen bench, H-pool for reads; link 4: F = 1 and the T1a part 3 premise). Make Remark B1.1 a tagged Lemma. Re-word link 8 as "T2 names the best WHAT". Add "Q to D_P" and "WHAT-then-HOW separation" as MISSING.
4. **The T5 Setting adds joint hypotheses that the tag does not name.** These are one N, aligned indices, one R and one M for all families.
   Fix: define H-read(joint) and H-kron(joint) in A.3 and put them in the T5 tag.
5. **Conjecture D1 is ill-posed.** On discrete mu_N it is a tautology. With convolution it is false in general. No limit measure is named.
   Fix: restate it as a limit (mu_N to mu weakly, continuous kernels, operator square root on L2(mu), matrix eigenvectors converge to eigenfunctions). Name "kernel Gram in place of C" as a hypothesis.
