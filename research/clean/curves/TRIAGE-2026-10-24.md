## How to read this file

**Scope.** A row is a formal item: Theorem, Lemma, Proposition, Corollary, Statement, Definition, Conjecture,
Construction, Remark, Observation, or a ledger row with a status. Checks (R1, X6, N4 and so on) are not rows. A check
appears only through the Statement that carries it. An item that appears in several ledgers gets ONE row with its final
status.

**Kind.**
| Kind | Meaning |
|---|---|
| STRUCTURAL | says what the coarse network IS (which units, which write, which symmetry, which object) |
| BOOKKEEPING | true of any quadratic, any ReLU, any composition (normal equations, Jensen, chain rule, rank counting) |
| MEASUREMENT | a number on the real network or the toy, even when it is labelled Proposition or Statement |
| NEGATIVE | a refuted claim, or a proved impossibility |

**Bin.**
| Bin | Meaning |
|---|---|
| (a) | THEOREM: content to prove in the new paper. The note names T0-T4 or "new" |
| (b) | HYPOTHESIS: an assumption about the network or the data. The note names the H- |
| (c) | LOG ONLY: about this network or this run, or a general fact that no T needs ("general fact, off the chain") |
| (d) | LEMMA: a proved result or a definition that a T-proof uses |

General facts that land in (c) still appear in the section "Facts known for sure".

**Hypotheses.** The three planned ones, plus the ones this triage proposes.
| Name | Content | Status |
|---|---|---|
| H-clean | the family is an orbit of a group up to eps | planned. Must respect N-Prop 6.1 (see note below) |
| H-sym | the input law is invariant under the group | planned |
| H-contour | inputs are random smooth contours (Markov direction process on position x orientation) | planned |
| H-stat | the weights are a stationary point of loss + (lam/2) norm^2 | proposed. Premise of P-Thm 1, 2, 5, 23, 24 |
| H-sgd | SGD with step eta is stationary in distribution, i.i.d. minibatches | proposed. Premise of P-Thm 31 |
| H-span | a coarse unit computes a non-negative combination of its children's outputs | proposed (P assumption L1) |
| H-metric | one output metric for all images | proposed (P assumption L2). Likely false as stated |
| H-uniform | with the true gates, the output metric can be replaced by Pi = I - 11^T/n | proposed (N-Stmt 26.3) |
| H-indep | gates are independent of the metric above them (K-FAC, mean field, postulate P3) | proposed. True at the first edge, false deeper |
| H-event | gates open as whole circuit events (postulate P2) | proposed. Needed by T4 |
| H-pattern | error weighting keeps the order of co-firing (P-Conj B) | proposed |
| H-transfer | the network's own norm is close to the natural-image norm (N-L8) | proposed |
| H-selfstat | the statistic read from the weights equals the statistic of the training mix (N theta-stat) | proposed. T4 tries to replace it |

**Note on H-clean.** N-Prop 6.1 proves that a ReLU layer admits no continuous orthogonal symmetry on its channels. It
allows permutations. So H-clean should say: a finite cyclic group C_n permutes the family members and rotates the
window in the plane, up to eps. N-Lem 4.2 (equal norms, circulant Gram) holds unchanged in that form.
