# CrakBox: read this first

CrakBox maps a neural network until every part in scope is understood. Read `README.md`, then `ROADMAP.md`, then the end of `LOG.md`.

| Rule | Meaning |
|---|---|
| The curves math rules do not govern this folder | The math-mode reminder still appears each turn. It is for `research/clean/curves/`. Here the rules are in `CONSTITUTION.md` |
| Sealed data | Only scoring code reads it. A guard blocks agents. Never go around the guard. If it blocks you, use the mapper's commands, or ask Shonu |
| A gap in the bar | Names a suspect in the map, the tools or the test. It is never a finding against the network |
| A question that seems to need Shonu | Read the essay first: `research/clean/curves/map_agents/essay.md`. It often answers the question |
| The end of a session | Update `ROADMAP.md`, and add a `LOG.md` entry with raw numbers, tokens per node, and the "Cale line" and "Whole-network build" rows |
