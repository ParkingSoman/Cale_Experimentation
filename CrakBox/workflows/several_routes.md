Strong firings split by what feeds them. Each route is a clue, and an offshoot that arrives by its own route is recursive generalization (essay lines 147, 399).

1. `bundles NODE`. Open each sheet. What does each bundle share? Which inputs mark it?
2. `deep NODE`. Is there one pattern under the bundles? Ask what the strangest bundle shares with the largest one.
3. For each bundle with a real effect, name a route in the card: its id, its exact inputs, and its own words.
4. Write a prediction per route that could fail, and test the weakest with `probe` or `edit`.

The main job goes in `distinction`. A route that has no link to the rest goes in `unread`, with what you tried. A judge tests each route alone, with the other routes filled.
